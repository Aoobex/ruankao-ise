  • 签名用私钥，验签用公钥；加密用对方公钥，解密用自己私钥。
  • 数字签名提供完整性 + 身份认证 + 抗抵赖，不提供机密性。
  • 数字信封：对称密钥加密数据，接收方公钥加密会话密钥。
  • RSA：n=pq，φ(n)=(p-1)(q-1)，e·d mod φ(n)=1。
  • DH 不能抗中间人；ECB 相同明文块→相同密文块；CBC 加密不能并行、解密可以。
  • 分组模式：CTR 可并行可随机访问；OFB 可预计算、一位错只影响一位。
  • 唯密文 / 已知明文 / 选择明文 / 选择密文 —— 攻击者能力由弱到强。

  • IPSec：AH 只认证（协议号 51）、ESP 加密+认证（50）、IKE 用 UDP 500。
  • 隧道模式用于网关到网关，传输模式用于主机到主机；AH 不能过 NAT。
  • SSL VPN 用 443，免客户端、按应用授权；IPSec VPN 适合网关互联。
  • ARP 欺骗根源：ARP 无认证；防御用静态绑定、DAI（依赖 DHCP Snooping 表）。
  • DNSSEC 只保证解析结果真实完整，不加密。
  • IPv6 基本首部固定 40 字节，无校验和。

四、攻击与防御一句话

  • SQL 注入：根本防御 = 参数化查询（预编译）；WAF 只是补充。
  • XSS：根本防御 = 按 HTML 上下文输出编码；HttpOnly 只保护 Cookie。
  • CSRF：根本防御 = 随机 Token 校验 / SameSite；不是 HTTPS。
  • 文件上传：白名单 + 重命名 + 存非 Web 目录 + 目录禁止执行。
  • XXE：禁用 XML 外部实体。
  • SSRF：169.254.169.254 是云元数据，可拿临时凭据。
  • 越权：普通用户干管理员的活 = 垂直越权。
  • CC 攻击：模拟合法请求耗资源；SYN Flood：占满半连接队列。
  • DNS 反射放大：伪造受害者源地址。
  • OWASP Top 10（2021）第一是访问控制失效，不是注入。
  • OWASP 2021 十项：访问控制失效、加密机制失效、注入、不安全设计、安全配置错误、易受攻击组件、身份认证失效、软件数据完整性失效、日志监控失效、SSRF。

五、设备与体系

  • 防火墙防不了：内网攻击、病毒、绕过（手机热点）、内部人员。
  • 包过滤看五元组、无状态、规则自上而下匹配；状态检测维护会话表。
  • 应用代理最安全也最慢；屏蔽子网（DMZ）安全性最高。
  • iptables 四表：filter / nat / mangle / raw；filter 三链：INPUT / FORWARD / OUTPUT。
  • 放行网站：-A INPUT -p tcp --dport 80 -j ACCEPT；默认拒绝 -P INPUT DROP；清空 -F。
  • 对外网站只开 80/443；数据库 3306 只允许应用服务器访问。
  • 网闸用于非 TCP/IP 摆渡；单向导入用于"只出不进"。
  • IDS 旁路告警，IPS 串联阻断；CIDF 四件：产生器、分析器、响应单元、事件数据库。
  • 误用检测=特征库，只知已知、误报低；异常检测=基线，能发现未知、误报高。
  • NIDS 部署在交换机镜像口；HIDS 看日志与文件完整性。
  • 审计是事后措施；蜜罐是诱捕。

六、恶意代码与认证

  • 蠕虫：主动扫描、自我复制、不需宿主。木马：伪装、不自我复制、可远程控制。
  • 病毒四特性：隐蔽、传染、潜伏、破坏；三部件：复制传染、隐藏、破坏。
  • 蠕虫四模块：探测、传播、引擎、负载。
  • 特征码只能查已知，多态/加壳/未知变种无效。
  • 认证四依据：所知（口令）、所有（U 盾）、生物特征、行为特征。
  • 口令存储：加盐哈希，不是加密、不是 Base64。
  • Kerberos 用对称密码，要求时间同步；AS 发 TGT，TGS 发票据。
  • PKI：CA 签发/吊销，RA 审核身份，CRL 列表，OCSP 实时查询。
  • DAC 看 ACL；MAC 看标签（BLP：不上读、不下写）；RBAC 看角色；ABAC 看属性。
  • Linux 权限 rwxr-xr-- = 754；/etc/shadow 存哈希，权限 400。
  • Windows：访问令牌含 SID，DACL 管访问，SACL 管审计。

七、管理与计算

  • 风险 = 资产 + 威胁 + 脆弱性；风险值 = 可能性 × 影响。
  • 四处置：规避、转移（买保险）、减轻、接受；处理后仍有残余风险。
  • SLE = 资产价值 × 暴露因子；ALE = SLE × ARO。
  • 可用性 A = MTBF/(MTBF+MTTR)；串联相乘，并联 1-∏(1-Ai)。
  • RTO = 恢复时间目标；RPO = 恢复点目标（能丢多少数据）。
  • 容灾：冷 / 温 / 热站点；备份 3-2-1：3 份、2 种介质、1 份异地。
  • 子网：/26 块 64、/27 块 32、/28 块 16；可用主机 = 2^h − 2。
  • 取证优先易失数据：内存/连接 → 磁盘 → 备份；镜像算 MD5/SHA-256 比对。
